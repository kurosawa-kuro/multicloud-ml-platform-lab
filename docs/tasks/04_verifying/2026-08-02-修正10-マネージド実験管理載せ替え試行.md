## 判定と根拠

### 採用: **A（併存）** —— Neon が正本、実験管理は補助

- **B（置換）を退けた**: ① 要件 UC-003「Neon の SELECT だけで5基盤比較」が単一テーブル
  前提。実験管理は基盤ごとに別物なので置換すると横断集計層を**自前で**作る羽目になり、
  「自前を減らす」動機と矛盾する ② `attempt` は Neon の同一 (platform, stage) 過去行数+1 が
  正本で、移すと permission friction が別物になる ③ 比較6列のうち native に載るのは
  `status` だけで、残りは generic な params 止まり＝**格納できるが比較軸として引けない**
- **C（不採用）を退けた**: 基盤ネイティブの実験管理がどう見えるかは比較材料そのもの。
  コストは config フィールド1つ + 既定 OFF に収まった

### PoC ブランチが要らなかった理由

判定材料は SDK の契約とコードから静的に出た。実際、実装は adapter 内に閉じ、
`PlatformAdapter` / `ml_runs` スキーマ / 共通層には一切触れていない。

## 実装

| 基盤 | 変更 |
|---|---|
| Vertex | `VertexConfig.experiment` + `VertexAdapter._tracked` override（事後複写）+ `experiment_observer.py` |
| SageMaker | `SageMakerConfig.experiment` + `create_training_job` の `ExperimentConfig`（事後 API は生やさない） |
| Azure ML / Databricks | **既にネイティブ対応済み**。フィールド名を `experiment` へ統一しただけ |
| Snowflake | 変更なし（実験の概念が無いことを docstring に明記） |

### 設計上の要点

- **共通層に置かない。** Experiments は5基盤に並ぶ実装が無いので、`ports.py` の
  「5基盤ぶんの実装が並ぶものだけ port にする」に従い各 adapter に閉じる
- **既定値も揃えない。** Vertex / SageMaker は OFF を選べるが Azure / Databricks には
  「実験に属さない」状態が存在しない。揃えると嘘になる
- **Snowflake に空フィールドを置かない。** 「あるが未設定」に見え、比較レポートで
  「設定すれば使える」と誤読される
- 観測は非致命（失敗しても Neon の記録と adapter の戻り値は変えない）

### この検証で見つけて直した欠陥3件

1. **実験が未作成だと複写できない** —— `ExperimentRun.create` は実験を作らない。
   `get_or_create` を前段に入れた
2. **decorator が `merge_run_params` を落として修正07 の resume を壊していた** ——
   実測で学習成功行が `params: {}` になり `register` が停止。→ 最終的に
   **記録契約そのものを交差点まで縮める根本再設計**へ（下記）
3. **`check_residual.py` が Experiments を見ていなかった** —— `registered_model` と
   同じ構造の穴（SDK が作るので destroy で消えない）。`experiment_run` を検査項目に追加

## 設計の作り直し（owner 指摘を3度受けて最終形へ）

| 段階 | 形 | 何が誤りだったか |
|---|---|---|
| 1 | sink decorator | 学習成功行が複写されない（抑制の下流）＋ 記録契約を落として resume を破壊 |
| 2 | core に `RunObserver` Protocol + 共通層フック | **実装が1つしか無い抽象を core に置いた。** ML コード側の都合から考え、5基盤から逆算する向きが逆だった |
| 3 | **最終形: 各 adapter に閉じる** | — |

派生して、記録スパイン自体も交差点まで縮めた（`RunSink` は `record_run` /
`next_attempt` の2メソッドに固定。受け渡しの永続化は driver 機能 `resume.persist_handoff` へ）。
経緯は [decision-log](../../decisions/decision-log.md) 2026-08-02 の各項。
