# 大改修 P3: 計測スパインの再配置（core/telemetry → src/telemetry）

Weight Class: **Heavy**（Task Contract Full）/ 親調査: [大改修 調査と方針 第2版](../01_idea/2026-08-02-大改修-5インフラ制約起点の再設計-調査と方針.md) §5-P3
実施前に **SPEC.md** を書く。**Owner Approval 必須（移設先名の判断を含む）。P2 の後に実施**（runtime が telemetry を import するため置き場を先に確定してから、が手戻りゼロの順 — ただし本 task の判断が P2 の SPEC に入力されるため、**判断だけ先行**してよい）。

## Goal

`core/telemetry`（Platform/Tier/WritePath/PLATFORM_TIER を持つラボ固有の計測層）を core の外へ移設し、`core/` を「5インフラの制約の交差点のみ」（ml + app）に縮める。あわせて core/app に残る基盤知識2点を処置する。

## Value

integrity（「core は基盤を知らない」が enum レベルでも真になる）/ docs canonicalization。

## Scope

- `core/telemetry` → `src/telemetry/` へ移設（import 54ファイルの機械的更新）
- **配布側の同時修正（文字列一致で拾えない・漏らすと5基盤中2つが起動時に落ちる）**: 学習 Dockerfile に `COPY src/telemetry` / Snowflake zip `included` に追加。serving イメージは変更不要（core/app は telemetry 非依存を確認済み）。wheel / orchestrator は自動
- 既存番人の同一コミット更新: `test_packaging_contract`（zip 内の telemetry パス）/ `test_core_boundaries` の stdlib-only 検査の移設
- 新番人: 「core 配下に Platform enum・基盤 env 名が存在しない」
- predictor のシム正規化（3 env 名 → serving シムが `MODEL_DIR` へ正規化。3基盤とも成立を実測確認済み）— **シム相当ロジックのテスト追加を条件に**実施
- D5 潜在バグの修正: `serving_image_uri or training_image_uri` フォールバック → 未設定は即エラー

## Non-scope

- `src/core/ml/**` への変更（tree hash 不変を守る）。**`DATASET_NAME`（constants.py）の帰属変更は tree hash を変えるため本 task から分離**し、5基盤 run 再取得と同時期の別 task へ
- logging_setup の GCP 固有部（既に env ゲート済み・一度も有効化されていない = 作業不要。親調査 訂正7）
- Neon env 名の正本化（→ P4。telemetry には置かない — 親調査 訂正8）

## Risk

- 移設は tree hash を変えない（`src/core/ml` の外）が、配布2点の同時修正漏れが即起動不能になる
- トップレベル名 `telemetry` は PyPI 同名パッケージと衝突しうる（現状依存なし・実害なし。判断として記録）

## Change Condition

移設先名の owner 判断確定 + P1 完了 + P2 完了（または P2 SPEC との同時設計）。

## Done Condition

`make test` 緑（更新番人含む）+ `core/` 配下に基盤知識ゼロの新番人が緑 + zip / Dockerfile の契約テストが新配置を pin + predictor 正規化はシム側テストで担保。実クラウド確認は一括 EL4 で。

## Owner-only Decisions

- 移設先名: `src/telemetry/`（推奨・PyPI 衝突は記録の上で許容）/ 代替案
- predictor シム正規化を本 task に含めるか分割するか（テスト追加コストが規模の過半を占める場合）

## Capability Boundary

クラウド資格情報・実接続は使わない。

## Allowed Paths

`src/**`（`src/core/ml/**` を除く）/ `docker/**` / `tests/**` / `pyproject.toml` / `docs/02_architecture.md` / 本 task と SPEC.md

## Forbidden Paths

`src/core/ml/**` / `docs/comparison/**` / `sql/**` / `infra/**`

## Rollback Trigger

- tree hash が変わった（`git` で `src/core/ml` に diff が出た）— 即差し戻し
- 計画外の番人赤 / 移設後に telemetry が platforms を import し始めた（層の向きの逆転）

## Evidence Required

Level 2: 移設前後で wheel / zip / 学習イメージの中身が期待どおりであることの契約テスト + 全 import の解決（`make test`）。predictor 正規化は5レイアウト（Tier A 3基盤）の既存 parametrize + 新シムテストの両緑。
